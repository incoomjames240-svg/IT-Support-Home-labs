# Active Directory Home Lab

## Objective
Practise managing users, groups, and organizational units
in a Windows Server lab.

## Environment
- VMware Workstation
- Windows Server 2022
- Windows 10 client
- Lab domain: metally.local

## Work Practised
- Organized Active Directory objects into departmental OUs.
- Created and managed lab user accounts.
- Created security groups for departments and support roles.
- Practised investigating user sign-in problems.
